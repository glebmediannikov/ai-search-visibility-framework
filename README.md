# AI Search Visibility Framework

A practical, marketing-oriented framework for reviewing content for **AI-assisted discovery / Answer Engine Optimization (AEO)**.

## Purpose

Traditional SEO remains essential, but content increasingly needs to work across search engines, AI-generated answers, assistants, and other discovery surfaces.

This framework reviews eight dimensions:

1. Intent coverage
2. Entity clarity
3. Answer structure
4. Evidence and sourcing
5. FAQ coverage
6. Structured data
7. Content freshness
8. Internal linking

The weights in `aeo_scoring_framework.csv` can be adjusted by business model or content type.

## How I would use it

A marketing/content team can score priority pages, combine the score with Search Console and conversion data, and create a roadmap based on:

**Business value × discoverability gap × implementation effort**

## What this demonstrates

- AEO strategy
- Content governance
- Information architecture
- Search-intent thinking
- AI-era discoverability
- Prioritization frameworks

This is a strategic portfolio framework, not a claim that any single score determines inclusion in an AI-generated answer.
